# Projeto Integrado — StrideZone

## A Empresa
StrideZone — e-commerce de tênis (fictícia)

## Ramo de Atuação
Varejo online de calçados esportivos e casuais (tênis de corrida, casual e streetwear/skate)

## O Problema
A StrideZone enfrenta ruptura de estoque em modelos populares e excesso de estoque parado em modelos de baixa saída, sem um sistema de previsão de demanda. O grupo pretende usar Gestão de Projetos para estruturar a solução, Análise de Dados para identificar padrões de venda e KPIs, Pesquisa Operacional para otimizar compras e distribuição de estoque entre os centros de distribuição, e Segurança da Informação para proteger os dados dos clientes e definir controles de acesso ao sistema.
